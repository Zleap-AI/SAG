# MCP 工具参考

所有工具返回 MCP text content。空态统一返回中文占位文案，不抛异常——判断关键词即可分支。

---

## list_sources()

列出当前可访问的全部信源。

**参数**: 无。

**返回示例**:
```
可访问的知识来源：
- 产品文档（source_id=src_prod_001）· 12 文档 · 340 分块
- 技术博客（source_id=src_blog_002）· 5 文档 · 89 分块
```

**空态**: `（暂无可用信源）`

**使用规则**:
- 全库连接时的**第一步**。取得 source_id 后再做后续操作。
- 即使信源只有一个也要调用——确认范围防止过期假设。

---

## list_documents(source_id: str = "")

列出指定信源下的文档列表。

**参数**:
| 参数 | 类型 | 说明 |
|---|---|---|
| source_id | string | 可选。不传则列出全库文档。 |

**返回示例**:
```
- 产品手册.pdf · id=doc_001 · ready · 120 分块
- 更新日志.md · id=doc_002 · processing · 0 分块
```

**空态**: `（暂无文档）`

**状态说明**:
| 状态 | 含义 | 可否检索 |
|---|---|---|
| ready | 处理完成 | ✅ |
| processing | 解析/抽取中 | ❌ 需等待 |
| error | 处理失败 | ❌ 需重新上传 |

## outline(document_id: str)

返回文档的层级大纲（标题 + chunk_id），按阅读顺序排列。

**参数**:
| 参数 | 类型 | 说明 |
|---|---|---|
| document_id | string | 必填。从 list_documents 获取。 |

**返回示例**:
```
1. 概述（chunk_id=chunk_001）
  1.1 项目背景（chunk_id=chunk_002）
  1.2 技术选型（chunk_id=chunk_003）
2. 快速开始（chunk_id=chunk_004）
  2.1 安装（chunk_id=chunk_005）
  2.2 配置（chunk_id=chunk_006）
```

**空态/处理中**: `（文档处理中，暂无大纲）`

**使用规则**:
- 定位章节位置后，用 get_chunk 读具体内容。
- 不要整个 outline 读完再逐 chunk 读——只取需要的章节。

## search(query: str, top_k: int = 8, source_id: str = "")

语义检索。自然语言问题 → 带编号证据块。

**参数**:
| 参数 | 类型 | 说明 |
|---|---|---|
| query | string | 必填。自然语言查询。 |
| top_k | int | 可选，默认 8。返回结果数。 |
| source_id | string | 可选。限定检索范围。 |

**返回示例**:
```
[1] 授权流程概述（chunk_id=chunk_042）
授权分为三步：用户发起请求，主管在线审批，系统自动记录并通知。

[2] 权限模型设计（chunk_id=chunk_078）
系统采用 RBAC 模型，支持角色、用户组、资源三级粒度。
```

**空态**: `（未找到匹配内容）`

**使用规则**:
- 回答时引用 `[n]` 编号标注每条事实。
- search 失败（LLM 未配置/离线）时返回结构化错误说明，告知用户检查模型配置。
- 同一轮对话复用已有结果，不要重复调用。

## grep(pattern: str, limit: int = 20, source_id: str = "")

大小写不敏感的 LIKE 精确匹配。`%` 和 `_` 已自动转义。

**参数**:
| 参数 | 类型 | 说明 |
|---|---|---|
| pattern | string | 必填。匹配模式。 |
| limit | int | 可选，默认 20。上限 50。 |
| source_id | string | 可选。限定检索范围。 |

**返回示例**:
```
[1] 配置项说明（chunk_id=chunk_015）
……SAG_MAX_CHUNK_SIZE 控制分块大小，默认值为 512 ……

[2] 性能调优（chunk_id=chunk_089）
……调整 SAG_MAX_CHUNK_SIZE 时需同步修改向量维度……
```

**空态**: `（未找到匹配 "pattern" 的内容）`

**使用规则**:
- 第一次无结果时可换同义词或缩短 pattern 再试一次。最多 2 次。
- 上下文已包含 ±240 字符，大部分场景不需要再调 get_chunk。

## get_chunk(chunk_id: str, source_id: str = "")

读取单个分块的完整原文。

**参数**:
| 参数 | 类型 | 说明 |
|---|---|---|
| chunk_id | string | 必填。来自 search/outline/grep。 |
| source_id | string | 可选。限定时可提速。 |

**返回示例**:
```
## 授权流程概述

授权分为三步：
1. 用户发起请求
2. 主管在线审批
3. 系统自动记录并通知

请求需要在 24 小时内完成审批，超时自动退回。
```

**空态**: `（未找到该分块）`

**使用规则**:
- 引用溯源的终点——用户追问出处时调用。
- 不要在初答时逐条 get_chunk——先用 search 覆盖全貌。

## read(document_id: str, offset: int = 1, limit: int = 120)

按行分页读取原始文件。

**参数**:
| 参数 | 类型 | 说明 |
|---|---|---|
| document_id | string | 必填。 |
| offset | int | 可选，默认第 1 行。 |
| limit | int | 可选，默认 120 行，上限 500。 |

**返回示例**:
```
第 1-120 行 / 共 560 行
1 | # 产品手册
2 |
3 | ## 第一章 概述
4 | 本产品是……
……
120 | 下一章将介绍安装步骤。
```

**空态**: `（文档不存在或无法读取）`

**使用规则**:
- **禁止一次 read 整个文件**——始终分页，每次 ≤ 120 行。
- 先 outline 定位章节 → 估算 offset → 按需分页 read。
- 翻页：offset = 上次结束行号 + 1。

## get_entity(name: str, source_id: str = "")

查询实体的相关事件上下文。先精确名称匹配、再子串匹配。

**参数**:
| 参数 | 类型 | 说明 |
|---|---|---|
| name | string | 必填。实体名称。 |
| source_id | string | 可选。 |

**返回示例**:
```
实体：张三 · 类型：人物
相关事件：
- 张三于 2024 年加入团队（chunk_id=chunk_031）
- 张三负责核心模块开发（chunk_id=chunk_056）
```

**空态**: `（未找到相关实体）` — 此时建议用 search 替代。

## 空态文案速查

| 工具 | 空态/异常返回 |
|---|---|
| list_sources | `（暂无可用信源）` |
| list_documents | `（暂无文档）` |
| outline | `（文档处理中，暂无大纲）` |
| search | `（未找到匹配内容）` |
| grep | `（未找到匹配 "pattern" 的内容）` |
| get_chunk | `（未找到该分块）` |
| read | `（文档不存在或无法读取）` |
| get_entity | `（未找到相关实体）` |
